# CTE Pathway Equity Trends

Interactive dashboard of Career Technical Education pathway completion and disproportionate impact for California districts and charter schools, graduation cohorts 2019-2025, with roll-ups for the San Diego & Imperial region.

Source data: California School Dashboard College/Career Indicator research files (CDE). Prepared by WestEd for the San Diego & Imperial Counties Community Colleges Regional Consortium.
